### 4. DEMO WALKTHROUGH (5 minutes)

Show in this exact order (maps to his pain points):

#### e) WhatsApp Integration (30 sec)

## KEY REMINDERS
- **Talk less, listen more.** He should talk 60% of the time.
- **Don't oversell features.** Show 5-6 screens max. Keep it fast.
- **Name HIS pain back to him.** "You mentioned [X] — this is how FlowOps handles it."
- **Assume the sale.** Don't ask "are you interested?" — ask "when do you want to start?"
- **Be human.** You know this guy from Screenline. This is a catch-up, not a boardroom pitch.
