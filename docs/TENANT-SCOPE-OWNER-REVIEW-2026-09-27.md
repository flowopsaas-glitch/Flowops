  | **S — needs company scope** | Real tenant data access; add `companyId`
    to the where/args. Code change — goes through normal review. |
  | **V — verified in-tenant upstream** | Caller already proves the row
    belongs to the tenant (lookup-by-id-then-write pattern). Document the
    proof in the row. |
  | **U — unclear, needs investigation** | Cannot be decided from the
    signature alone. |
