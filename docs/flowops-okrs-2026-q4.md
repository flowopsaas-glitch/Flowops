### How to use the cockpit
1. Owner console → **OKRs** → *New objective* (set quarter `2026-Q4`).
2. Expand the objective → add each Key Result with its unit, start and target.
3. As you progress, edit each KR's **Current** value — objective and portfolio
   progress recompute automatically, and status colour shifts (green ≥70%,
   amber 40–69%, red <40%, blue = achieved).
