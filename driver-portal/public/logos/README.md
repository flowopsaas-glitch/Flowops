# FlowOps Logo Assets

Place your logo files here:
- logo-primary.png (main logo)
- logo-white.png (white version)
- logo-icon.svg (icon only)
- logo-full.svg (full logo SVG)

The current logo image should be converted to:
1. PNG for general use
2. SVG for scalability
3. WebP for performance
4. Multiple sizes: 512x512, 192x192, 64x64, 32x32
